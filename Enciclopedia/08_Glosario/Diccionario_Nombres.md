## 📝 Reglas de Nomenclatura
1. **Familiaridad**: Usar nombres NASA para objetos conocidos.
2. **Identidad**: Usar nombres Inventados para lugares clave de la trama.
3. **Precisión**: Usar códigos GDU para catalogación científica.
