## 🎯 Conceptos Clave

- **Multiverso**: Globo circular gigante que contiene universos
- **Universo**: Burbuja dentro de un multiverso
- **Planeta**: Cuerpo celeste dentro de un universo
- **Agujero Blanco**: Portal entre multiversos
- **Agujero de Gusano**: Portal entre universos del mismo multiverso
